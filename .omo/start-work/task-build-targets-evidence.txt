== Key Finding ==
ESP32-S3 lean builds are ~10KB smaller than ESP32 classic PPP builds.
S3 uses only 54% of 8MB flash partition vs 60% of 4MB on classic.
S3 is the clear single-MCU winner — native USB eliminates Pico bridge.
AtomS3U with USB-A plugs directly into mobo header.
